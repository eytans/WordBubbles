# Photo cards

This folder contains the first optional photo-style visual pack for WordBubbles.

The 12 cards were generated as one consistent contact sheet with OpenAI image generation, then cropped and compressed into square local JPEG assets. They contain no text, logos, people, or trademarks. The source contact sheet is kept in this folder as `contact-sheet.png` for maintenance reference and is not listed as a Flutter asset.

Included subjects:

- cat
- dog
- apple
- banana
- car
- bus
- fish
- tree
- book
- ball
- sun
- flower

Emoji mode remains the default. Photo mode uses these cards where available and falls back to the word's emoji for the rest of the vocabulary until more cards are added.
